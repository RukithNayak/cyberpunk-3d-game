# Asset provenance records

Every shipped or reviewable asset gets a record alongside its editable source or in a linked manifest. Record enough to identify the origin, permitted use, modifications, and exact export.

## Required fields

- Stable asset ID, title, role, brief, dimensions in meters, pivot convention, Blender source path, export path, and SHA-256 hashes for source and delivered files.
- Creation date, author/agent, Blender version, script/repository revision, export format and settings, target Godot version, and QA/import evidence links.
- Origin type: original manual work, procedural code, AI-generated, or third-party source. For AI work, record service/model and version when known, generation date, prompt or prompt-file path, seed/settings when available, and any human edits. Keep prompts and generated source images with the asset record when allowed.
- For downloaded or third-party assets: creator, source URL, exact license name/version, license URL or local license copy, attribution text, download date, modifications, and redistribution/commercial-use conditions. Do not include an asset until its license is checked for the intended use.
- For textures, separately record source and license or generation details for each externally sourced map; identify color space and packed-channel layout.
