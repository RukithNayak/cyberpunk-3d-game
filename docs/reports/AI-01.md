# AI-01 — Faction-aware perception

**Status:** Accepted, Stage 1. **Owner:** Main Agent. **Date:** 23 October 2026.

Added `NpcPerception` with runtime-only visual contact, most recently seen position, last-known position, and a bounded sound-event history. Visual updates require a live target inside the configured range with an unobstructed physics ray. Occlusion or range loss clears current contact and preserves prior knowledge. Sound events use inclusive distance checks and do not run a ray, so walls do not block investigation stimuli. `FactionRules` reads CORE-02 `FactionState` on every query; unknown factions remain neither hostile nor allied.

The defaults recorded in the owning task are engineering values only: 20 m sight range, collision layer mask 1, and 16 retained sound events.
