# AI-04 — Serialize simplified simulation on unload

**Status:** Accepted, Stage 1<br>
**Owner:** Main Agent<br>
**Date:** 23 October 2026 (Asia/Kolkata)

## Delivered

- Added `NpcSimulationRecord`, a transient coordinator that listens to synchronous `WorldManager.chunk_pre_unload` events and commits complete registry replacements before relinquishing active NPC actors.
- Durable records under existing NPC UUIDs contain schema version, chunk/faction IDs, health, world position, normalized quaternion rotation, and dead status. Records contain no Node references; unrelated entity state is preserved.
- `TacticalAgent` can capture and restore durable simulation fields, clear volatile targets/perception/combat timers before unload, disable navigation, and reject post-unload ticks. Restore waits for navigation readiness and active UUID ownership prevents duplicates.
- Added `ai_unload` coverage for pursuit, attack/stun, reverse-order chunk re-entry, navigation gating, rotation/health restoration, duplicate ownership, snapshot adapter validation, and durable death.
- Regression-first evidence: before implementation, `ai_unload` exited 1 because `npc_simulation_record.gd` was missing and the service availability assertion failed.
