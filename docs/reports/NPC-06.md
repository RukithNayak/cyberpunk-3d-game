# NPC-06 — Dialogue, mission interaction and local model evaluation

**Status:** Accepted 24 October 2026 (Asia/Kolkata), Main Agent.  
**Scope:** Stage 1 only; one named NPC, one authored retrieval contract, event-driven journal, generation blips, and a no-download evaluation of an existing local model.

## Implemented

- Added a fullscreen responsive dialogue scene using the shared Cyberpunk Theme and container layout. Mara Vega's panel shows transcript/status, request/send/cancel/close controls, text/subtitle toggle, generated-audio volume and mute, contract request/accept/recover actions, and a side mission journal.
- Added `MissionDirector.mission_changed(mission_id, state, credits)` after committed offers and state transitions. Replayed idempotent calls and snapshot hydration do not emit user-facing duplicate events.
- Added a data-only journal view that reconstructs mission state and credit balance from the director snapshot.
- Added a deterministic, locally synthesized 100 ms tone. It has bounded volume/mute controls and stops after timeout, cancellation, mute or close.
- Added a playable fixture scene: `godot --path game res://tests/scenes/dialogue_demo.tscn`. The authored contract path works without Ollama; objective completion still checks the registry's collected state through `MissionDirector`.
- Trade without authorized merchant stock/panel is plainly reported unavailable. Model output remains validated; an unknown proposed action routes to fallback and never commits.
- Added a deterministic mock-offline mode, mission signal regressions, and a focused UI suite covering valid output, offline, malformed/unsupported output, cancel/timeout, mission completion/reward, journal reconstruction, mute/volume, and focus return.

## Limits / follow-up

- Manual listening and human click-through feedback were not collected. Audio construction/playback state, stop paths, keyboard focus, and a rendered fullscreen UI were checked in code/tests and the capture.
- One local model request at a time was sampled; there is no concurrency, memory-pressure, repeatability, or combined render/combat benchmark. WORLD-06 owns those measurements and thresholds.
- This fixture is not attached to the current main combat scene. A production world interaction must supply the registry-backed cache-collection callback and return-focus control. It cannot grant a reward directly.
- The model license is identified, not approved for redistribution; NPC-07 owns that decision.
